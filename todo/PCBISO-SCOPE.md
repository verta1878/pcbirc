# PCBISO — ISO/CD-ROM File Area Indexer for PCBoard

## What It Does

Standalone utility. Mounts ISO images as drive letters, scans sources,
and generates PCBoard-format DIR file listings with FILE_ID.DIZ extraction.

Sysop creates the file area in PCBSETUP first, then uses PCBISO to
mount ISOs and populate file areas with listings.

## PCBoard File Area Structure

When a file area is created in PCBSETUP, these files are involved:

| File | Format | Purpose | Created by |
|------|--------|---------|-----------|
| DIR.LST | Binary (DirListType records) | List of all directories in conference | PCBSETUP |
| DLPATH.LST | Text | Download path list — physical file locations | PCBSETUP |
| DIR listing (e.g. DIR1) | Text | File descriptions shown to users | PCBFILER or PCBISO |
| DIR index (e.g. DIR1.IDX) | Binary (IdxHeader + filetype records) | Search index for DIR listing | PCBoard (auto) |

### DirListType Record (in DIR.LST)

```
DirPath[31]  — path to the DIR listing text file (e.g. C:\PCB\DIR\DIR1)
DskPath[31]  — physical path where files are stored (e.g. D:\FILES\)
DirDesc[36]  — description shown to users ("Shareware Games")
SortType     — sort order for the listing
```

### DIR Listing Text File Format

One line per file. Users see this when browsing:
```
DOOM.ZIP      2396000  08-13-26  DOOM shareware v1.9
FRACTINT.ZIP   485000  08-13-26  Fractal generator v20.0
```

### DIR Index (.IDX)

Binary index auto-created by PCBoard (createdirindex() in DIR.C).
Contains IdxHeader (file size/time/date of DIR listing + latest date)
followed by filetype records (filename + offset into DIR text file).

PCBoard regenerates the .IDX automatically when the DIR listing file
changes (checked via needtoresyncdirindex()). PCBISO does NOT need
to create or manage .IDX files.

## What PCBISO Reads

- **DIR.LST** — to find configured file areas and their physical paths

## What PCBISO Writes

- **DIR listing text files** — file descriptions for each file area

## What PCBoard Handles Automatically

- **DIR .IDX files** — regenerated when DIR listing changes

## Commands

| Command | Description |
|---------|-------------|
| PCBISO /MOUNT <iso> | Mount ISO image, assign next available drive letter |
| PCBISO /UNMOUNT <drive> | Release drive letter |
| PCBISO /INDEX <drive\|path> | Scan source, generate PCBoard DIR listing |
| PCBISO /INDEX ALL | Index all configured sources |
| PCBISO /REBUILD <drive\|path> | Delete and regenerate DIR listing from scratch |
| PCBISO /REBUILD ALL | Rebuild all file area indexes |
| PCBISO /LIST | Quick list of mounted ISOs and configured paths |
| PCBISO /STATUS | Detailed view: file counts, last indexed date, status |

## Error Messages

```
PCBISO: E:\ not found — drive not mounted or not available.
PCBISO: C:\PCB\FILES\ not found — path does not exist.
PCBISO: E:\ is not configured as a file area in PCBSETUP.
```

## Supported Sources

| Source | Example | SlowDrives |
|--------|---------|------------|
| CD-ROM drive letter | D:\ | Yes — mark D in SlowDrives |
| Mounted ISO as drive letter | E:\ | Yes — mark E in SlowDrives |
| Local directory | C:\ISOS\CDROM1\ | No — already fast |

## Data Files

| File | Purpose |
|------|---------|
| PCBISO.DAT | Mount table — which ISOs on which drive letters |
| DIR listings | PCBoard file area listings (generated by /INDEX) |

## Features

- Mounts ISO images as drive letters
- Reads DIR.LST to find configured file areas
- Scans directory tree recursively
- Generates PCBoard DIR listing text files
- Extracts FILE_ID.DIZ from ZIP and ARJ archives for descriptions
- Skips hidden/system files
- Update mode: rescan and add only new files to existing DIR listing
- Rebuild mode: regenerate from scratch for corrupted listings
- Persists mount table across reboots (PCBISO.DAT)
- Sysop menu integration: view status from inside PCBoard

## Sysop Workflow

1. Create file area in PCBSETUP (adds entry to DIR.LST with DirPath + DskPath)
2. Add drive letter to SlowDrives in PCBSETUP (if slow media)
3. PCBISO /MOUNT C:\ISOS\SHAREWARE.ISO — mounts as E:
4. PCBISO /INDEX E: — reads DIR.LST, scans E:\, writes DIR listing text file
5. Users browse files in PCBoard — PCBoard auto-creates .IDX
6. User downloads file — SlowDrives copies to TmpLoc, transfer succeeds
7. PCBISO /STATUS — sysop checks everything is working

## Drive Limits

**15.4:** SlowDrives[27] = 26 drive letters (A-Z).

**15.41 (Phase 5a):** SlowPaths[10][66] — path-based slow sources.
Requires PCBOARD.DAT extension + upd1541.exe.

## What PCBISO Does NOT Do

- Does not create file areas — PCBSETUP does that (writes DIR.LST)
- Does not create .IDX files — PCBoard does that automatically
- Does not handle file transfers — PCBoard + SlowDrives does that
- Does not modify PCBOARD.EXE or PCBOARD.DAT

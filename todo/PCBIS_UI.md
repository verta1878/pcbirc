# pcbis_ui — PCBoard Installation System Configuration

Full-screen text UI for configuring PCBoard 15.41 BBS.
Uses PCBoard's own SCRNIO/SCREEN TUI libraries.
Compiles with OpenWatcom 2.0 (DOS).

Part of pcbrevival (GPL v3.0).

## Usage

```bash
pcbis_ui [pcbis.cfg]        # Run TUI directly
pcbis -cfg                  # Via pcbis launcher script
pcbis_ui --help             # Print help and exit
pcbis_ui -?                 # Same
```

If no config path is given, defaults to `pcbis.cfg` in the current directory.

## Navigation

| Key | Action |
|-----|--------|
| Arrow Up/Down | Move highlight bar between fields |
| Enter | Edit the selected field inline |
| Letter key | Jump to menu item by hotkey |
| Backspace | Delete character while editing |
| Escape | Return to main menu from sub-screen |
| Q | Quit (from main menu) |
| S | Save configuration to pcbis.cfg |
| I | Run first-time setup (pcbis_initv) |

When editing a field, type the new value and press Enter to confirm
or Escape to cancel. The field displays with a blue background while
in edit mode.

## Config File Format

All settings saved to `pcbis.cfg` in key=value format. Comments begin
with `#`. The file is generated by Save (S) and read on startup.

```ini
# pcbis.cfg — PCBoard Installation System
# Generated by pcbis -cfg

# BBS Settings
bbs_name=PCBoard BBS
sysop_name=SYSOP
telnet_port=23
nodes=1

# Paths
pcb_root=/home/pcboard
pcb_data=/home/pcboard/data
fossil_driver=ADF
netmodem_path=/home/pcboard/netmodem

# DOSBox
dosbox_cycles=0
dosbox_output=surface

# FidoNet
fido_enabled=0
fido_address=1:1/1.0
fido_hub=
fido_binkp_port=24554
fido_inbound=/home/pcboard/fido/inbound
fido_outbound=/home/pcboard/fido/outbound
fido_nodelist=/home/pcboard/fido/nodelist

# Web Server
web_enabled=0
web_port=8080
web_root=/home/pcboard/DATA/default/www
web_title=PCBoard BBS
web_ansi_preview=1
web_file_browser=1

# FTP Server
ftp_enabled=0
ftp_port=21
ftp_root=/home/pcboard/files
ftp_anonymous=0
ftp_max_connections=10
ftp_banner=PCBoard 15.4 FTP Server
```

## Field Types

The TUI supports four field types:

| Type | Behavior |
|------|----------|
| String | Free-text entry up to field max length |
| Path | Same as string, used for directory paths |
| Integer | Numeric entry, converted with atoi() |
| Boolean | Toggles Yes/No on Enter (no typing needed) |

## UI Library: PCBoard SCRNIO/SCREEN

pcbis uses PCBoard's own SCRNIO and SCREEN libraries from the
source tree — the same TUI framework that PCBSETUP uses.

### PCBoard TUI Stack

```
SCREEN.LIB (4,913 lines — low-level)
├── box()         Draw single/double line boxes
├── boxcls()      Draw box and clear interior
├── cls()         Clear screen
├── gotoxy()      Position cursor
├── fastprint()   Direct video memory write
├── fastcenter()  Centered text
├── scrollup()    Scroll region up
├── scrolldn()    Scroll region down
├── setatt()      Set color attribute in region
├── memsavescreen()    Save/restore screen state
├── memrestorescreen()
├── defwindow()   Define named window coordinates
├── openwindow()  Open saved window
└── closewindow() Close and restore

SCRNIO.LIB (3,208 lines — high-level)
├── initmenu()    Create lettered menu
├── addmenu()     Add menu item with handler function
├── menusel()     Display menu with arrow-key navigation
├── initquest()   Initialize field array
├── addquest()    Define form field (type, position, mask, validator)
├── readscrn()    Display form and handle field editing
├── freescrn()    Free field memory
├── inputstr()    Single string input with mask
├── inputnum()    Numeric input with type conversion
├── inputline()   Line editor with cursor keys
├── showhelp()    Context-sensitive help display
├── generalscreen()  Standard header/footer template
└── interact()    Main input loop
```

### Why PCBoard's own TUI

1. **Same look and feel** — pcbis looks like PCBSETUP, which
   sysops already know. Same color scheme, same key bindings,
   same form field behavior.

2. **Battle-tested** — this code has been in production since
   PCBoard 14.x. Every edge case (screen save/restore, cursor
   positioning, color handling, box drawing) is already handled.

3. **Declarative forms** — PCBSETUP's `addquest()` pattern lets
   us define entire screens as field arrays. No manual cursor
   positioning or input parsing. Example from ACCOUNT.C:

```c
FldType P[13];
initquest(P, 13);
addquest(P, 0, vBOOL, HELP_ACCT, YESNO,  3, 5, 1,
         "Enable Accounting", &PcbData.EnableAccounting, CLEAR, NULL);
addquest(P, 1, vUPSTR, HELP_FILE, ALLFILE, 3, 6, 30,
         "Config File", PcbData.AccountConfig, NOCLEARFLD, checkfile);
readscrn(P, 12, 0, "Accounting", "Configuration", 1, CLEAR);
freescrn(P, 12);
```

4. **No external dependencies** — compiles under OpenWatcom with
   zero additional libraries.

5. **Field types built in** — vBOOL (Y/N), vSTR (string), vUPSTR
   (uppercase string), vINT, vLONG, vFLOAT, vDATE, vHEXINT,
   vBYTE, vUNSIGNED. Input masks (YESNO, ALLFILE, ALLNUM, etc).
   Tab/arrow navigation. Automatic clearing.

## PCBDRAW Integration

PCBDRAW is built into pcbis as menu item D. The sysop can create
and edit ANSI art for display files, bulletins, and welcome screens
directly from the installer without launching a separate program.

### Launching from pcbis

```
┌─── PCBoard Installation System ────────────────────┐
│                                                     │
│   G  General Settings                               │
│   P  Paths & Directories                            │
│   M  Modem / Telnet                                 │
│   N  Node Configuration                             │
│   S  Security Levels                                │
│   F  FidoNet Setup                                  │
│   Q  FREQ / Magic Names                             │
│   D  PCBDRAW — ANSI Art Editor                      │
│   X  Exit and Save                                  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

When the sysop selects D, pcbis launches PCBDRAW with the current
PCBoard paths pre-configured:
- Default save directory: PCBoard's display file path
- File browser starts in the display file directory
- .PCB format is the default save format (with @X codes)

### Network Detection and Teleconference Mode

PCBDRAW's teleconference (client/server) mode requires TCP
networking. When loaded from pcbis, PCBDRAW checks for a
network stack on startup:

**DOS:**
1. Check for packet driver at INT 60h-6Fh
2. If no packet driver, check for WATTCP.CFG
3. If neither found, networking is disabled

**Behavior when no network is found:**
- Teleconference menu items are grayed out
- /SERVER and /CLIENT command-line options show:
  "Network not available — no packet driver or WATTCP detected"
- All local drawing features work normally
- No error on startup — networking silently disabled

**Behavior when network is available:**
- Full teleconference mode enabled
- Server binds to TCP port 3693
- Client connects to specified hostname:port
- Status bar shows connection state

### File Workflow

When editing from pcbis, PCBDRAW saves directly to PCBoard
paths:

```
PCBDRAW → Save as .PCB
  ├── C:\PCB\GEN\WELCOME.PCB     (welcome screen)
  ├── C:\PCB\GEN\BRDCAST.PCB     (broadcast message)
  ├── C:\PCB\GEN\BLT\BLT1.PCB   (bulletin 1)
  ├── C:\PCB\GEN\NEWS.PCB        (news file)
  └── C:\PCB\GEN\LOGON.PCB       (logon display)
```

The sysop creates the art, saves, and the BBS immediately
uses it — no file copying or format conversion needed.

### Animation Use Cases

Animated .PCB files created in PCBDRAW work as:
- Welcome screen animations (plays when caller connects)
- Bulletin animations (plays when caller reads bulletin)
- Inter-node chat announcements
- Event notifications (e.g. new file upload animation)

PCBoard displays them using its built-in @DELAY:n@ and @CLS@
tag processing — no special PPE or door program needed.

## System Tray Support (i386 / Windows)

The i386 (Windows) build of pcbis uses utrayit by sysop/0 to
minimize to the Windows system tray notification area. This
lets the sysop run pcbis in the background while the BBS operates.

### utrayit (from fpc264irc/libs/utrayit)

Cross-platform console-window tray/minimize class for FPC:

**Windows (Win2000 through Win11):**
- Minimize to system tray with notification icon
- Left-click tray icon to restore
- Background thread runs the message pump
- Auto-registers for TaskbarCreated (survives Explorer restart)
- Icon loaded from embedded MAINICON resource or console class
- Automatic cleanup at unit finalization — no stuck tray icons

**Unix (Linux, FreeBSD):**
- Sends XTWINOPS escape sequences to terminal
- CSI 2 t = iconify, CSI 1 t = de-iconify
- Works in xterm and compatible emulators
- TrayConsole falls back to MinimizeConsole (no portable tray)

**DOS (go32v2):**
- Graceful stubs — all methods return False
- Programs compile and run, tray features silently unavailable

### pcbis Integration

```c
#include "utrayit.h"

/* After BBS starts successfully */
if (tray_supported())
    tray_to_tray("PCBoard 15.41 — click to restore");
else if (tray_console_supported())
    tray_minimize();

/* On shutdown */
tray_cleanup();
```

APPLY

  Extract BOTH parts into the same directory to get the full working tree.

  Windows:
    Right-click each zip -> Extract Here (same folder)
    OR: unzip both into an empty pcbirc/ dir

  Linux/Mac:
    mkdir -p /path/to/pcbirc
    cd /path/to/pcbirc
    unzip -o pcbirc-full-v165-source-part1of2.zip
    unzip -o pcbirc-full-v165-source-part2of2.zip

  Overlap: CHECKSUMS trio appears in both zips (same content, harmless).

VERIFY

  cd /path/to/pcbirc
  md5sum -c CHECKSUMS.md5
  # Should report: 10385 OK, 0 failures.

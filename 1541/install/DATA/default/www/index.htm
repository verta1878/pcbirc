Welcome to PCBoard 15.4

PCBoard is a professional-grade Bulletin Board System that has been serving the online community since 1983. Version 15.4 represents over a decade of continuous development, making it the most capable and reliable BBS platform available.

Whether you are running a single-line hobby board or a commercial multi-node system, PCBoard provides the tools, performance, and flexibility you need.

■ System Features

Messaging & Conferences
• Up to 65,535 message conferences
• FidoNet echomail (built-in PCBTOSS)
• UUCP Internet mail gateway
• QWK offline mail packets
• Full-screen message editor
• Message threading and replies
• Carbon copy and forwarding
• Conference-level security

File Management
• Unlimited file directories
• Batch uploads and downloads
• ZModem, YModem, XModem protocols
• Automatic virus scanning hooks
• File descriptions and searching
• Duplicate file detection
• Upload credit and ratio system
 Security & Access
• 255 security levels
• Per-conference access control
• Password protection and expiry
• Caller verification system
• Audit trail and logging
• Callback verification
• Subscription account management

Multi-Node Operation
• Up to 250 simultaneous nodes
• Node-to-node chat
• Global messaging between nodes
• Shared file and message bases
• Record and file locking
• Node activity monitoring
• Per-node configuration

■ FidoNet Integration

PCBoard 15.4 includes a complete, built-in FidoNet Technology Network implementation. No external tosser or mail processor required.

PCBTOSSBuilt-in echomail tosser — imports and exports .PKT packets
EMSI/WaZooInbound mailer sessions — receive mail automatically
PCBFU.EXEFidoNet utility — maintenance, analysis, area setup
RoutingFull echomail routing with SEEN-BY and passthrough support
NetmailPoint-to-point .MSG handling with file attach
FREQFile request processing during inbound sessions

■ PPL — PCBoard Programming Language

PCBoard includes PPL, a powerful compiled scripting language that lets sysops create custom doors, menus, questionnaires, and online applications without leaving the BBS environment. PPL programs run natively inside PCBoard with full access to the user record, message bases, and display system.

PPLC.EXEPPL compiler — compiles .PPS source to .PPE executables
200+ functionsString handling, file I/O, database access, ANSI display
Event-drivenLogin, logoff, conference join, command intercept hooks

### What the Box Contained

Based on Wikipedia description and Roy/SAC's blog:

- **Box**: Purple/white cardboard box with PCBoard logo
  (globe with horizontal lines + "PCBoard" in italic serif)
  and "Professional Bulletin Board Software" tagline
- **Manuals**: Printed sysop manual and PPL reference handbook
  (sold separately or bundled)
- **Disks**: 3x 3.5" HD floppy disks (purple labels)
- **License bag**: Clear plastic bag containing license
  certificate with serial number and node count
- **License types**: 2-line ($150), 5, 10, 25, 50, 100,
  250, 1000 nodes (stacking licenses)

### Pricing (circa 1994-1996)

- 2-node license: $150
- PPLC compiler standalone: <$100
- PPLC with BBS license: <$50
- Printed manual: sold separately
- Printed PPL reference: sold separately

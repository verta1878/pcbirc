Configuring OS/2 Warp to connect to the system is really quite easy to do.
Before you begin, make sure you have all of the necessary components:

  * OS/2 Warp (Connect or Server is okay too)
  * Bonus Pack (comes with Warp)
  * Make sure the bonus pack is installed properly (particularly the 
    Internet Connection for OS/2 portion).
    
With this much accomplished, you're ready to begin:

Getting The Script File
-----------------------
With this archive, you received a file named OS2SLIP.CMD.  This file is
required to get you connected to our BBS.  Copy it to a directory where 
you want it to reside permanently and make note of this subdirectory--it 
will be used later in this process.

Adding A New Internet Provider
------------------------------
Now we are ready to do the bulk of the installation work.  Here we use OS/2
built-in capability to set up other providers.  Let's begin.

  1.  Open the "IBM Information Superhighway" icon on the desktop.
  2.  Open the "IBM Internet Connection for OS/2" folder.
  3.  Open the "Internet Utilities" folder.
  4.  Double-click on the "Dial Other Internet Providers" icon.
  5.  Click "Add Provider".
  
Entering Provider Information
-----------------------------  
  1.  Enter "Salt Air" in the Provider Name field.
  2.  Enter "SCRIPT" in the "Logon ID" field.
  3.  Enter "SCRIPT" in the "Password" field.
  4.  Enter "SaltAir" in the "Nickname" field.
  5.  Enter "SCRIPT" in the "Phone Number" field. 
  6.  Enter the full path and filename to OS2SLIP.CMD file talked about
      at the beginning of this document.  Following the filename, you need
      to put a space, the modem dialing command, your first name, last name,
      and password (each separated by a space).
      Example:  C:\SCRIPTS\OS2SLIP.CMD ATDT18012611686 joe smith password
  7.  Make sure SLIP is selected in the "Connection Type" box.
  8.  Click "Next".

Entering Connection Information
-------------------------------
  1.  Set MTU Size to 1006.
  2.  Leave VJ Compression unchecked.
  3.  Enter 206.173.168.40 in the "Domain Nameserver" field.
  4.  Enter PCBOARD.COM in the "Your Domain Name" field.
  5.  Click "Next".
  
Entering Server Information
---------------------------
  1.  Click Next - there is no news or mail servers available on this system.
 
Entering Modem Information
--------------------------
  1.  Select the "Com Port" you want to use for dialing the system.  COM2 
      is quite often the one to use.  If unsure, contact whoever built your
      computer.
  2.  Set the port speed to 38400.
  3.  Click on "OK".
  
Dialing The System
------------------
  1.  Make sure the "Dial Other Internet Providers" program is loaded.   This
      is loaded by selecting the following from the desktop:
      
          * IBM Information Superhighway
          * Internet Connection for OS/2
          * Internet Utilities
          * Dial Other Internet Providers

  2.  Double click on the "SaltAir" nickname entry.
  
Congratulations
---------------
  You now have a SLIP connection active on your system.  Load up your favorite
  browser or Internet application and HAVE FUN!

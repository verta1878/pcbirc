SAC Tools Releases

SAC released only a few tools during the years. SAC was not a tool group. The PPE section was removed for the same reason, even if it looked like a good fit at the beginning. The tools are nothing special and were primarily for internal use only. There are certainly better tools available from others, which do a better job, but to be consistent and to make sure that the collection is complete, did I put them up for download on the site anyway.

The viewer was introduced with SAC Pack #25 and was used to show the content of the artpack on Windows PCs. If you are looking for a good ANSI/ASCII art viewer for Windows, check out ACIDView for Windows, which is available fro download on this page too.

The Draw 4.61 - ASCII/ANSI Editor (PC/MS DOS) - 291KB
TheDraw is a DOS tool to create and modify ASCIIs and ANSIs, especially ANSIs and block ASCIIs which are not supported by Windows anymore. I personally use TheDraw since 1992 as replacement for the crappy tool "AnsiDraw" which I have also available, if you like "pain" hehe. I never made the switch to ACiDDraw as so many others, even if it had some more features than TheDraw which was IMO superior to ACiDView at the beginning. You will probably have a bit of a hard time if DOS is completely alien to you, but give it a shot anyway. It's fun.

ACiDDraw V1.25 - ANSI Editor for MS DOS - 82KB
In the early ninties was the ASCII and ANSI text art scene split in half. Not really as bad as you might think though. The artists at that time either used ACiDDraw or TheDraw, the only two editiors that provided the features needed by the leading text artists. TheDraw was the older one and lead the pack for a while, but ACiDDraw catched up and became towards the end of the MS DOS and BBS realm the predominant editor. It's greatest feature was the support of virtually unlimited lines on ANSI vs TheDraw which was limited to a maximum of 100 lines. Artists that created ANSI's beyond 100 lines were rare though.

Windows users should use the Windows version of this editor. I only put the DOS version up for history sake.

VGA Editors (for DOS only)
Deluxe Paint II Enhanced V3.0 - Image Editor (PC/MS DOS) - 547KB
Deluxe Paint was THE pixel graphics tool on the AMIGA 500. The PC version came a bit later and development was not continued on the PC like on the Amiga, where DP made it to version 4 before it was stopped there as well. It was still ahead of its time when it came out.

At that time was MS Paint for Windows 3.0 quite "hip" and "Autodesk Animator" (the maker of AutoCad) the McLaren F1 of PC pixel software.

This version of Deluxe Paint is the "enhanced version" which supports "Super VGA" (256 colors BEYOND 320x200) to some degree (not really, but they made an effort). It should still run on most people's Windows XP PC.
Deluxe Paint Animation - Image Editor (PC/MS DOS) - 374KB
Deluxe Paint Animation was a special version of Deluxe Paint that supported the creation of animations in the propriatary format .ANM. It only supports the standard VGA resolution of 320x200 pixels and 256 colors. Animation features were part of the standard feature of newer versions of DP on the Amiga, which were not ported to the IBM PC.

There is a video codec for Windows that enables the playback of Deluxe Paint Animation files via Windows Media Player. You can download the Deluxe Paint Animation ANM codec here (94 KB).
Autodesk Animator Pro - Image Editor (PC/MS DOS) - 1,100 KB
Autodesk Animator Pro is a very function rich image editor for MS DOS that also has many nice tools and functionalities to create animations (videos). The program works with GIF and PCX images and uses the videos format .FLI (FLIC) for the animations. The editor supports Super VGA. I believe up to a resolution of 1024x768 and 256 Colors. The animator features are limited to standard VGA as far as I can recall.

To be able to play-back AAPro FLIC videos on your Windows 32/64 bit PC and Windows Media Player, you need to install a special video codec first. You can download the Autodesk Animator V1.11 Codec here
Pixler 1.0 Beta 3 - Image Editor (PC/MS DOS) - 537 KB
Pixler 1.0 Beta 3 by Rage from 1997 is a free Deluxe Paint clone for MS DOS. It is actually more a clone of the Amiga Version of Deluxe Paint 4 and has many features of that version, which is missing the the Deluxe Paint 2 version for the PC.
GraphX 2.0 Beta - Image Editor (PC/MS DOS) - 449 KB
GraphX 2.0 Beta 96.1% by Sunset Design is a pixel graphics program for MS DOS, which supports 60 different graphic modes and multiple image formats such as GIF, LBM, BMP, PCX and PKM
Master Draw 3.6 - Image Editor (PC/MS DOS) - 155 KB
Master Draw V3.6 by Arkham is a free pixel graphics paint program for MS DOS with SVGA support.
VGA Paint 386 Home V1.3 - Image Editor (PC/MS DOS) - 326 KB
VGA Paint 386 V1.3 is another free Deluxe Paint clone for MS DOS. It supports various graphics formats, including LBM/IFF, BMP, PCX, PBM and PPM. It supports Vesa 1.2 and 2.0 SVGA and Win95 long file names.
DeluxeDraw 2.01 Demo - Image Editor (PC/MS DOS) - 342 KB
DeluxeDraw 2.01 Demo Version by Timothy Edwin Roden from 1998. A DeluxePaint Animation clone, but with support of SVGA. Its unfortunately not free like the other DP clones. This demo version does not allow to save your images.

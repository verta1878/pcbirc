## What the Box Contained

Based on Wikipedia article (written by Roy/SAC) and pcboard.be:

- **Box**: Purple/white cardboard, PCBoard globe logo
- **Printed manual**: Sysop guide (sold separately or bundled)
- **Printed PPL reference**: Programming handbook (sold separately)
- **3x 3.5" HD floppies**: Purple labels with typewriter font
- **License bag**: Clear plastic bag with license certificate
- **License certificate**: Serial number + node count
- **Node counts**: 2 ($150), 5, 10, 25, 50, 100, 250, 1000
- **PPLC compiler**: <$100 standalone, <$50 with BBS license

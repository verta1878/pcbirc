# Toolkit Docs — PCBoard Data Structure / File Format Reference

Clark's developer documentation for the file formats and data
structures the toolkit works with (PCBOARD.DAT, PCBOARD.SYS, USERS,
message base, FIDO, etc.). Two dated revisions, both from DEVELOP.ZIP:

- `devkit/`   — newer revision (last update 07/23/95, covers through
                PCBoard 15.x). Use this as the primary reference.
- `develop9/` — older revision (last update 08/13/94, covers 14.0
                through 15.0). Kept for the earlier version history.

These are the "read the struct docs before declaring structs" source
for anyone working on the 15.3 toolkit. The same material (as .TXT)
also appears in docs/PCBXDOT/DOCDEV.

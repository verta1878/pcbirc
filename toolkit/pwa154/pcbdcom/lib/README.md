# Pre-built .OBJ library variants

Not shipped in source-only releases. Build from `../src/` per your
compiler and memory model. See `../docs/SDK.md` for naming convention.

Targets:
- BC 3.1: PCBCOMM_B{S,M,C,L,H}.OBJ
- MSC 7.0: PCBCOMM_7{S,M,C,L,H}.OBJ
- MSC 8.0: PCBCOMM_8{S,M,C,L,H}.OBJ
- OpenWatcom: PCBCOMM_W{L,F}.OBJ

Build helper Makefiles to be added in `../src/`.

# pcbdcom SDK

Drop-in replacement for WCSC's COMMDRV.OBJ. Links into PCBoard and any
other COMM-DRV-aware DOS application without source changes.

- **src/**       Source (GPLv3)
- **inc/**       Headers (`PCBDCOM.H` for consumers)
- **lib/**       Pre-built .OBJ variants (see `lib/README.md`)
- **docs/**      `SDK.md` + `LINKOUT.md`
- **examples/**  simple.c, multiport.c, tsrless.c

See `docs/SDK.md` to start.

# pcbbinkp — BinkP/1.1 FidoNet Mailer

BinkP protocol implementation for PCBoard FidoNet networking.

- `binkp.c` / `binkp.h` — BinkP/1.1 protocol engine
- `binkpauth.c` — CRAM-MD5 authentication
- `bso.c` — Binkley-Style Outbound directory handler
- `bso_clark_style.c` — BSO implementation in Clark's coding style

2,008 lines. Handles FidoNet mail and file transfers over TCP.

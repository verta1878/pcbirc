# platform — Platform-Specific Distributions

Clark's platform support packages, as distributed:

- `Pcbwin95.zip` — Windows 95 support
- `pcbinet.zip` — Internet/TCP support
- `pcbos2_1.zip` — OS/2 configuration docs
- `pcbvcom.zip` — Virtual COM port support
- `pcbwinnt.zip` — Windows NT support
- `fossil/` — FOSSIL driver files

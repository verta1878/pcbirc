# pcbdraw — ANSI Art Viewer/Editor

PCBoard's ANSI art editor, ported from ansiedit (Mystic BBS).

- `pcbdraw.c` / `pcbdraw.h` — main editor
- `pdansi.c` — ANSI rendering
- `pdcanvas.c` — drawing canvas
- `pdnet.c` — network/collaborative editing
- `utrayit.c` / `utrayit.h` — utility tray
- `ciadraw_ref/` — CIADraw reference material

1,826 lines of our code. Port source in `wip/pcbdraw/`.

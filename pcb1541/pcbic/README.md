# PCBIC — PCBoard InterCom

Scaffold for reproducing Clark's PCBIC (InterCom) suite.

InterCom provided internet services for PCBoard: Telnet, FTP,
Gopher, Finger, Ping, PPP/SLIP dialup, and WHO.

- `src/pcbic.c` — scaffold (Phase 27)
- `Pcbic12.zip` — Clark's PCBIC 1.2 distribution (encrypted, password unknown)

The zip contains: Pcbic.exe, Pcbic2.exe, PCBICCFG.EXE, PCBICEVT.EXE,
TESTIC.EXE, RUNINET.PPE/.PPS, Win95/OS2 dial-up scripts, data files
(menus, FTP/Gopher/Telnet screens), PCBIC.PDF, PCBIC.DOC.

Password is wasnt PCB153 (works on all other Clark zips).

QFront v1.0.0 — Installation Guide for PCBoard 15.3/15.4
=========================================================

pcbirc crew 2026 — evga/hexadecimal
github.com/verta1878/pcbirc


REQUIREMENTS
------------

  - PCBoard 15.3 or 15.4
  - DOS 5.0 or later (DOS4GW included)
  - FidoNet address assigned to your system
  - Modem or FOSSIL driver (optional for BinkP-only)


QUICK SETUP
-----------

  1. Create a directory for QFront:

     MD C:\QFRONT

  2. Copy all files from bin\dos\ to C:\QFRONT:

     COPY bin\dos\*.* C:\QFRONT

  3. Create the working directories:

     MD C:\QFRONT\INBOUND
     MD C:\QFRONT\OUTBOUND
     MD C:\QFRONT\NETMAIL
     MD C:\QFRONT\NODELIST
     MD C:\QFRONT\TEMP
     MD C:\QFRONT\BAD

  4. Edit QFRONT.CFG with your settings:

     Address=1:234/56           <- your FidoNet address
     Outbound=C:\QFRONT\OUTBOUND
     Inbound=C:\QFRONT\INBOUND
     TempInbound=C:\QFRONT\TEMP
     NetmailDir=C:\QFRONT\NETMAIL
     NodelistDir=C:\QFRONT\NODELIST
     NodelistBase=NODELIST
     ComPort=1                  <- your COM port (1-4)
     BaudRate=115200            <- locked DTE baud rate
     Tosser=C:\QFRONT\QSCAN.EXE
     LogFile=C:\QFRONT\QFRONT.LOG

  5. Place your nodelist file (NODELIST.xxx) in C:\QFRONT\NODELIST

  6. Compile the nodelist:

     C:\QFRONT\QNLIST.EXE C:\QFRONT\QFRONT.CFG


PCBOARD EVENT SETUP
-------------------

  QFront runs as an external event in PCBoard. Set it up in PCBSETUP:

  1. Run PCBSETUP
  2. Go to: File Locations -> Event Files
  3. Add a new event:

     Event Active .... Yes
     Event Time ...... 00:00    (or your preferred schedule)
     Event Buffer .... 0
     Runcode ......... 5        (or any free errorlevel)
     Runcode for
       Runcode File .. C:\PCB\EVENTS.BAT

  4. Create C:\PCB\EVENTS.BAT:

     @ECHO OFF
     IF %RUNCODE%==5 GOTO QFRONT
     GOTO END

     :QFRONT
     C:\QFRONT\QFRONT.EXE C:\QFRONT\QFRONT.CFG
     C:\QFRONT\QSCAN.EXE C:\QFRONT\QFRONT.CFG /TOSS
     :END

  This runs QFront to exchange mail, then QScan to toss incoming
  packets into your PCBoard message bases.


CONTINUOUS MAILER (BETWEEN CALLS)
---------------------------------

  To run QFront between calls (like a front-end mailer):

  1. In PCBSETUP -> System Options:
     Set "Run event between calls" to Yes

  2. In your BBS batch file (BOARD.BAT), add after PCBOARD.EXE:

     :LOOP
     PCBOARD.EXE
     IF ERRORLEVEL 5 GOTO MAILER
     GOTO END

     :MAILER
     C:\QFRONT\QFRONT.EXE C:\QFRONT\QFRONT.CFG
     C:\QFRONT\QSCAN.EXE C:\QFRONT\QFRONT.CFG /TOSS
     GOTO LOOP

     :END


PROGRAMS
--------

  QFRONT.EXE   Main mailer — handles modem, EMSI handshake, 
               Zmodem/Xmodem file transfer, session management.
               Polls nodes, answers incoming calls.

  QSCAN.EXE    Tosser/scanner — imports received FidoNet packets
               into PCBoard message bases (/TOSS), exports new
               messages as outbound packets (/SCAN).

  QNLIST.EXE   Nodelist compiler — compiles raw NODELIST.xxx and
               applies NODEDIFF.xxx updates.

  QFCONFIG.EXE TUI configuration editor — menu-driven setup.

  QFUTIL.EXE   Utility — create polls, send netmail, file requests
               from the command line.


QSCAN USAGE
------------

  QSCAN.EXE <config> /TOSS          Toss inbound packets
  QSCAN.EXE <config> /SCAN          Scan and export outbound
  QSCAN.EXE <config> /TOSS /SCAN    Both
  QSCAN.EXE <config> /TOSS /DEBUG   Verbose output


QNLIST USAGE
-------------

  QNLIST.EXE <config>               Compile nodelist
  QNLIST.EXE <config> /DIFF         Apply nodediff only


QFUTIL USAGE
-------------

  QFUTIL.EXE <config> /POLL 1:234/56        Create poll
  QFUTIL.EXE <config> /NETMAIL 1:234/56     Send netmail
  QFUTIL.EXE <config> /FREQ 1:234/56 FILE   File request


TROUBLESHOOTING
---------------

  No FOSSIL found:
    QFront checks for a FOSSIL driver first. If not found, it
    falls back to direct UART access. Make sure your COM port
    number and baud rate are correct in QFRONT.CFG.

  Cannot open nodelist:
    Run QNLIST.EXE to compile your nodelist first.

  Permission errors:
    Make sure all QFront directories exist and are writable.

  Debug mode:
    Add /DEBUG to any command line, or set Debug=1 in QFRONT.CFG
    for verbose logging.


FILES
-----

  QFRONT.CFG   Configuration file
  QFRONT.LOG   Activity log (created at runtime)
  QPOLLED.DAT  Recently polled nodes (cooldown tracking)
  QUNDIAL.DAT  Undialable nodes (max retries exceeded)
  QFIXUPS.DAT  Incomplete transfers to retry
  DOS4GW.EXE   DOS extender (required, ships with QFront)

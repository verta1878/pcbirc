WinFOSSIL v2.0.0 — Modern FOSSIL Driver

FOSSIL driver for Windows 7 through Windows 11 (32/64-bit).
COM port access + TCP/Telnet VMODEM mode.

Install: Run SETUP.EXE or copy files manually.
Config:  Control Panel > WinFOSSIL, or WNFOSCTL.EXE CLI.
Tray:    Run WNFOSSIL.EXE for system tray icon.

Files: FOSSIL.DLL, WNFOSSIL.EXE, WNFOSCTL.EXE, WNFOSSIL.CPL
Registry: HKLM\SOFTWARE\WinFOSSIL

GPLv3 — Recreated from Bryan Woodruff's WinFOSSIL (1996).

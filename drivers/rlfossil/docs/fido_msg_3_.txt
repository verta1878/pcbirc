RLFOSSIL is just an executable and config file, and I got the docs sent via
mail. It's not really in "releasable" state which is why I'm trying to source an
original archive. I will send it to you, along with my "parselog.com" program
which parses the log that EtherPPP spits out, setting the following environment 
variables: (used with Minuet, IRC etc)

set ip=
set gateway=
set netmask=255.255.255.0
set dns=128.102.16.10

The first two vary, the second two are hard coded.

It also creates wattcp.cfg:

---------------------------------------------------------------------
#
#WARNING! This file will be overwritten; do not make changes.
#

my_ip=
netmask=255.255.255.0
nameserver=128.102.16.10
gateway=
outport=23
handshake=2
---------------------------------------------------------------------

Of course this sort of thing is not required if you always have a constant IP
address setup...

Note the latter two lines. If these are omitted, RLFOSSIL seems to negotiate
rlogin first, which fails (with no clues as to why) when you're connecting to a 
system with VMODEM. (So far all of the fidonet systems I have connected to via
the net all run OS/2 with VMODEM, and BinkleyTerm 2.59. I'm being different by
running MS-DOS, RLFOSSIL and FD 2.12. :-) ).

I'll include the MoonRock source for PARSELOG too.

If anyone else is interested in RLFOSSIL (seamless telnet for any software which
uses a FOSSIL!) then I will try to dig up an original release archive. Note it
supports *inbound* "calls" too. :-)

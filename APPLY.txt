WHAT THIS RELEASE DOES

  Real INSTALL.DAT runs end-to-end for the first time.

  11 new directives implemented (29 of 60 total):

    @If / @Else / @EndIf / @Endif   - conditional branches
    @Goto / @Label                    - script-position jumps
    @Set                              - variable assignment
    @StrLen / @StrHead / @StrToken    - string utilities
    @Exists (as @If predicate)        - file existence check

  Plus a full recursive-descent expression evaluator supporting
  `[= [!  == != > < >= <= && || ()` on int and string operands,
  with @Func(...) inline invocation inside string literals (needed
  for Clark's nested-quote pattern like "@StrToken("@Fname",0," ")").

  Also handles trailing `@Group X` clause on `@File` as a per-directive
  filter (Clark's INSTALL.DAT uses `@File N @Out MAIN\CNAMES.IDX @Group n`
  to gate per-bulletin-board files).

  Verified end-to-end: real 42 KB INSTALL.DAT runs to `@Exit`,
  471 successful @File operations, 348 files byte-perfect vs
  pcb1541/install/dist/target/ reference (94.8% of placed).

RUNTIME NOTES

  New CLI arg:

                        v1.10.4 will render an interactive checkbox
                        menu; until then this simulates the selection.

  Full usage:
    ./install -a <redx-archives-dir> -t <install-target> \
              -r <path-to-redx> -g "abcdef" INSTALL.DAT

  For end-to-end tests use `-g "abcdefghijklmnopqrstuvwxyz"` to enable
  all group letters (catches bulletin-board flavors too).

  install.c stdin read is now tty-conditional: automated tests
  (stdin = /dev/null) skip the @Pause keypress; interactive runs
  behave as before.

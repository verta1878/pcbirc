ON THE LOCAL /analysis/ FOLDER

  /analysis/ lives at REPO ROOT and is gitignored. Its purpose:
  one archive's reverse-engineering scratch at a time. Layout on your
  local machine:

    <repo_root>/
    ├── analysis/                      (gitignored — never pushed)
    │   └── pcbic12/                   (ONE archive at a time)
    │       └── <current-target>/      (ONE binary in flight)
    │           └── ...raw decompile, working notes, local build...
    └── ...tracked tree...

  Rules:

  - Only ONE archive folder inside /analysis/ at any time. When
    pcbic12 work is done and cleaned source is in pcbic12/src/,
    delete /analysis/pcbic12/ and start /analysis/install/ (or
    whichever archive is next).
  - Only ONE binary in flight per archive at a time. Get it to
    `cmp -s <built> ../bin/<target>`, land cleaned source in
    pcb1541/<subsystem>/src/, then start the next.
  - Nothing in the tracked tree references /analysis/. It's invisible
    to git status. Nothing to modify when you delete it locally —
    the tracked reconstruction stands on src/ + bin/ alone.
  - Regenerable any time by re-running the disassembler against
    bin/<target>.

WHAT THIS RELEASE DOES

  Lands the 301-directive dispatch table in install-1011.c, replacing
  the v1.11.0 empty-main() stub. This is the skeleton of the entire
  INSTALL.EXE engine: every @-directive in Clark's binary maps to an
  enum ID via a string lookup table, with a minimal main loop that
  reads INSTALL.DAT, extracts @-tokens, uppercases, and dispatches.

  All handlers are stubs (dir_stub) — v1.11.2 will port the 60 real
  semantic handlers from install-1010.c.

  Family API link target (.DEF file, C0FL.OBJ startup, target OS byte
  0x01) deferred to v1.11.2 — ships alongside the semantic handler
  port, where the Family API imports actually matter.

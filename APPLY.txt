WHAT THIS RELEASE DOES

  Full 481 @File operations succeed against real INSTALL.DAT
  (matches reference tree total exactly). 394 files byte-perfect
  vs pcb1541/install/dist/target/ (94.0% of placed).

  10 new directives implemented (39 of 60 total):

    @MkDir / @Mkdir   - actually create the directory
    @ChDir            - change working dir (state-tracked)
    @ChDrive          - change working drive (state-tracked)
    @DirExists        - predicate: does dir exist
    @DefineDisk / @EndDisk  - disk-scope block semantics
    @Requires / @HardDisk / @Version  - project-metadata predicates

  Also fixed two @File parser bugs surfaced by real INSTALL.DAT:
    - `@Out DIR\*.*` glob: means "keep source filename under DIR/"
      (PCBMAIL.RED uses this heavily; without the fix, all 4 PCBMAIL
      files failed placement)
    - Missing `@Out`: destination defaults to source key
      (PCBOARD2.RED / OS/2 block uses this — 7-10 files failed
      placement without the fix)

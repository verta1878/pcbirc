WHAT THIS RELEASE DOES

  7 new directives implemented (56 of 60 total). Real system-hook
  handlers that generate CONFIG.SYS.pcb + AUTOEXEC.BAT.pcb drop-in
  files, and a @Finish block that executes post-install cleanup.

    @System(cmd)              - real shell-out with headless-safe default
    @SetConfig / @EndConfig   - CONFIG.SYS.pcb writer
    @SetAutoexec / @EndAutoexec - AUTOEXEC.BAT.pcb writer
    @Finish / @EndFinish      - post-install block (skipped by default)
    @Files = N                - FILES=N emitted inside @SetConfig
    @Path = "..."             - PATH=%PATH%;... emitted inside @SetAutoexec

WHAT'S NEW IN CLI

  --run-finish       Execute the @Finish block (default: skip).
                     When set, post-install @Delete calls remove
                     INIT.EXE/UPGRADE.EXE/VTF.EXE/PCBOS2/PPLCODE/
                     PCBSER.BAK per Clark's script.

  --exec-system      Actually shell out for @System(cmd) calls
                     (default: stub returns 0). Setting this means
                     install.c will try to run external commands
                     like VTF.EXE, INIT.EXE, PCBSETUP.EXE — these
                     don't exist in our tree, so failures are
                     expected. Useful when you have real DOS tools
                     available via DOSBox-X wrapper.

  Existing flags unchanged: -a/-t/-r/-g/-h.

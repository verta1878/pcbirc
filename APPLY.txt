WHAT THIS RELEASE DOES

  Wires the .RED archive extractor (redx) into install.c and adds
  6 file-operation directives:

    @BeginLib / @EndLib  - open/close an archive extraction context
    @File                - place one file from the current archive
                           (subclauses: @Out, @Size, @AppendTo)
    @Copy                - copy a file (non-archive source)
    @Delete              - remove a file or directory
    @FileAttr            - set file read-only attribute

  Cumulative: 18 of 60 semantically distinct @-directives implemented
  (up from 12 in v1.10.0).

  Verified: minimal test .DAT produces byte-perfect output vs
  pcb1541/install/dist/target/ on the file-op subset.

RUNTIME NOTES

  install.c needs the redx binary at runtime. Build it in the repo:
    cd pcb1541/install/archivers/redx && make

  Then either put redx in your PATH, or pass its path to install:
    ./install --redx /path/to/redx --archives /where/reds/live \
              --target /where/install/goes INSTALL.DAT

  Matches Clark's original shell-out pattern (INSTALL.EXE shells to
  DSZ/GSZ for external protocols; we shell to redx for archives).

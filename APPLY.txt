APPLY.txt — PCBoard 15.4x / pcbirc active changelog
====================================================

Entries 1-41 (v0.3.2+ through v0.3.3+(40), 2026-09-20 to 2026-09-24)
migrated to HISTORY.md under "## v0.3.2+ — Build-root, recoveries,
toolkit, OS/2 push".  Raw detail preserved in git history.

Build order: pcb153 PWA → pwa154 → OS/2 SDK (DOS + OS/2).
Delta154 waits until those are fully built.

ROOT = \OUT means <repo-root>\OUT.  The repo root directory can be
named anything.  Output goes to OUT\<branch>\ (e.g. OUT\pwa153\,
OUT\pwa153\os2\).

OPEN BLOCKERS (carried from entries 1-41):
  - CodeBase: c4base.lib (DOS/BC31) + b4.lib (OS/2) missing.
    Must compile from pcbcbase/CODEBASE/SOURCE/.
    Without them: PCBOARD.EXE has no dBASE, PCBOARD2.EXE cannot link.
    Upstream: https://github.com/MPSystemsServices/CodeBase-for-DBF
  - pcbkit_l.lib TC 2.01 build: never committed (167,768 B vs
    Borland's 241,144 B — TC builds 9 of 10 categories, no C++).
    PPLC maybe blocked on it.
  - TKLIB: 10 category libs built for BC31 LARGE only.  TC201 and
    MSC70 legs not done.  CVER steers paths not the compiler;
    -ml baked into TK.CFG.  BLDTK.BAT drives all 10.
    BLDTKOS2.CMD = OW2 / OS/2 / delta154 (one compiler, flat model).
  - SDK paths: PCBKIT/PCBKBC/PCBKMS MAK/CFG need ROOT=\OUT\BRANCH\
    SDK\COMPILER\BIN across 4 branches × 3 compilers.

================================================================

  - OS/2 PCBOARD2.EXE cannot link

(2.8 GB, URL link only — not cloned into repo).

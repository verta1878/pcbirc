WHAT THIS RELEASE DOES

  Switches the INSTALL.EXE build from a DOS/Windows NE target to the
  correct OS/2 Family API NE target, matching Clark's original binary.

  Three changes:
  - C0FL.OBJ (Family API startup) replaces C0L.OBJ (plain DOS)
  - TLINK /Toe (target OS byte 0x01 = OS/2) replaces /Twe (0x02)
  - INSTALL.DEF added (EXETYPE OS/2, PROTMODE, STACKSIZE 8192)

  Clark's INSTALL.EXE (verified at NE offset 0x1CA00): linker 5.10,
  target OS 0x01 (OS/2), flags 0x0002 (MULTIPLEDATA), 6 segments,
  stack 8000, imports DOSCALLS + KBDCALLS + VIOCALLS.

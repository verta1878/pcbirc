  10 new directives implemented (49 of 60 total). Real interactive

  --groups CLI arg + sensible defaults when running non-interactively.

    @GetString / @EndString                 - user string input
    @SetGroup / @ClearGroup                 - state mutators
    @AskOverwrite                           - accepted directive
    @Prompt                                 - prompt string setter

  reference.
